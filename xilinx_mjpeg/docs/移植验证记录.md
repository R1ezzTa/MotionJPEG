# Xilinx 移植验证记录

日期：2026-09-17。源工程与快照见项目 README。本次未修改原安路工程，也未接触用户的 Ubuntu 主机。

## RTL 适配

`line_group_ram` 默认分支改为 Vivado 块 RAM 推断，保留一拍同步读和读使能关闭后的输出保持。初次 FHD 检查发现前端生成亮度数据时还会对未使用的色度通道发起读取，地址可能超过逻辑深度；原安路原语使用向上取整的 2 次幂容量并截取有效地址位。移植后的 RAM 已保持相同行为，避免只按逻辑深度推断产生仿真/硬件差异。仿真增加实际读写地址碰撞和写越界检查。

完整 FHD 回归的首对完成帧周期分别是 2,988,156 与 2,988,574 拍。仿真假定 200 MHz 时，后者为 14.942870 ms。这不是板上帧率，因为 Xilinx 的实际 200 MHz 时序尚未收敛，输入测试源也遵守 ready。

小图证据保存在 `reports/mjpeg_board`，满宽证据保存在 `reports/mjpeg_wide`，FHD 部分证据单独保存在 `reports/mjpeg_fhd_partial`，不与完整回归结果混用。仿真通过目录包含 `tested_sources.json`；源哈希应结合对应测试目录查看，不把后加的测试参数误认为历史运行已使用。

## 综合与已知限制

双路 A35T：21,873 LUT、31,791 FF、42 BRAM Tile、84 DSP；LUT 超限，DRC 有两项 UTLZ-1 错误。

单路 A35T：10,120 LUT、16,205 FF、24.5 BRAM Tile、42 DSP；无资源超限 DRC 错误，仍有时序/复位及板级配置类警告。5 ns 综合后 WNS -1.347 ns。

双路 7020：20,805 LUT、31,287 FF、49 BRAM Tile、84 DSP；没有未解析黑盒。综合 DRC 有 DSP 流水级、RAM 异步控制和 PS7 默认配置等警告，未宣称零警告。7020 的 PS7 默认配置要求须在板级封装时处理，这不等于要求实现 ARM 图像应用。RAM 控制与复位关系需要在最终工程中验证，不能用屏蔽 DRC 代替修复。

此前三次属于 OOC 综合资源比较，未实施 `place_design`、`route_design`，未生成 bitstream，未设置板级引脚。5 ns 约束是在综合后加入用于时序报告；7020 WNS -1.352 ns，不能当作频率保证。随后需在完整约束参与综合、实现的流程下重新评估。

下一阶段先选定实际板卡、输入源和最低可接受画质，再做 PL 以太网封装及 Ubuntu 接收。相机 CDC、FIFO 深度、网络背压、CRC 与整帧异常恢复尚未完成系统验证。

## 用户确认 7010 后的补充评估

已确认板卡为领航者 7010；单路 `mjpeg_synth_top`、`MAX_WIDTH=1280`、目标器件 `xc7z010clg400-1`，候选时钟 100 MHz。综合脚本已改为综合前加载时钟 XDC，并保存构建参数及源码哈希。

实际结果：10,160 LUT、16,223 FF、24.5 BRAM Tile、42 DSP；占用率分别 57.73%、46.09%、40.83%、52.50%。综合后内部 Setup WNS +2.083 ns、TNS 0，Hold WHS +0.208 ns、THS 0；尚未布局布线或生成板卡配置。无资源超限类 DRC 错误，仍保留 RAM 异步控制、DSP 流水级及 PS7 默认配置警告。

本次未修改算法 RTL，仅验证单路参数能够在该器件完成综合。历史双路功能回归不等于该单路参数的完整功能回归。执行脚本已通过 PowerShell 语法检查；原始资源、时序、DRC、时钟和构建清单位于 `reports/synth_xc7z010clg400-1_1ch_1280px_20260917_223219`。具体阶段目标与剩余资源见 [7010 实施方案](领航者7010实施方案.md)。
