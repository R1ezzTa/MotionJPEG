# 当前控制与传输接口

项目为单路摄像头，USB 数据格式为 MBLK，图像载荷为完整标准 Baseline JPEG。PC 接收器只解包、解码、显示和设置板卡参数。

## USB 命令

| 命令 | 行为 |
| --- | --- |
| `C` / `S` | 开始／排完当前帧后停止；停止同时关灯 |
| `Q` 或 `1` / `2` / `3` | 循环画质或选择 Q60 / Q75 / Q85 |
| `L` / `l` | 约两秒补光／立即关灯 |
| `Nxx\n` | 降噪强度，十六进制 00～FF |
| `Bxx\n` | 二值化亮度阈值，十六进制 00～FF |
| `Exx\n` | Sobel 边缘阈值，十六进制 00～FF |
| `Mxx\n` | 00 彩色、01 灰度、02 二值化、03 Sobel |

多字节设置在换行后原子提交。解析载荷期间，十六进制 C/F 或非法 S/L 不解释为启停／补光命令。错误载荷排到换行，100 ms 无数据恢复空闲；板载键不受解析状态阻塞。停止优先于同时开始或补光。

KEY0 启停，KEY1 画质，KEY2 补光，KEY3 停止并关灯。LED0 显示运行／等待初始化，LED1/2 显示画质，LED3 显示补光／错误。数码管显示一秒窗口成功压缩帧数。

## MBLK

所有整数为小端。包头为 8 字节：`"MBLK"`、1 字节 kind、1 字节 flags、2 字节 body 长度。

| kind | body | 含义 |
| --- | --- | --- |
| 0 | frame_id + 至多 1024 字节 | JPEG 数据块；flags 表示首块、末块、abort 和通道 |
| 1 | 28 字节 | 帧描述符：帧号、64 位时间戳、载荷长度、尺寸、gray、错误状态 |
| 2 | 20 字节 | 窗口号、输入／成功／失败 FPS、累计成功帧数 |
| 3 | 24 字节 | 帧号、输入／JPEG／总周期、输入等待／输出等待周期 |
| 4 | 28 字节 | USB 窗口与周期分类计数 |
| 5 / 6 | 空 | END / START |
| 7 | 32 字节 | 摄像头初始化、芯片 ID、配置索引、采样时钟、帧／丢帧／溢出／字节数、控制状态 |
| 8 | 12 字节 | 预处理请求、当前模式及阈值、开始帧数 |

时间戳单位为 100 MHz 编码时钟周期。帧号与时间戳必须连续／递增；失败帧通过 abort 和描述符状态显式报告。FPS 与摄像头状态使用相同窗口，停止时状态仍更新。

`block_records.py`检查包长、顺序、JPEG 边界、描述符长度和 abort 一致性。`camera_receiver.py`进一步检查独立解码、尺寸、帧号、时间戳及摄像头性能。标准 JPEG 不依赖前一帧，RESET 或重连会开启新的接收会话。
