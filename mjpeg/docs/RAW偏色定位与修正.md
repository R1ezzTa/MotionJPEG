# RAW 偏色：ISP 翻转与像素相位（2026-09-28）

当前 1080p30 RAW 路径的主要偏绿来自摄像头的 ISP 翻转设置与光学 RAW 像素相位不匹配。实板对照支持将 profile 5 的 `3820` 从 `46` 改为 `42`，保留 sensor vflip、清除 ISP vflip，继续按 BGGR 插值。该配置在当前模块、裁剪、采样及 RAW 输出组合下明显减弱绿调，图像方向和裁剪范围保持一致。尚未使用外部标准色彩目标完成白平衡/色彩校准。

## 判定依据

同一 JPEG 经 Pillow 与 Windows GDI+ 解码，各通道区域均值差小于 0.006，证明此前全局绿色已存在于 JPEG 表达的像素中。FPGA 对已知 Bayer 输入的颜色公式、边界和像素时序通过独立数值对照，进一步定位到摄像头 RAW 与 ISP 的相位配合。

临时诊断固件复用 profile 5 的 SCCB 初始化、采样时钟和 DVP 捕获。在每个 8×8 原始区域保留相邻 2×2 像素，使用独立 BRAM 保存 480×270 RAW 样本后发送；没有 JPEG、Bayer 插值或 PC 色彩修正。寄存器读写均核对读回，主要对照冻结 AEC/AGC。诊断固件经过仿真、时序、DRC、CDC 和 bus-skew 检查，各次 RAW 捕获 FIFO 溢出均为 0。

初次通道增益探测和内部色条显示 `3820=46` 时 ISP 将 R 分配到偶行奇列、B 分配到奇行偶列，G 分配到另外两个位置，即 GRBG。仅把 FPGA 改为 GRBG 后，内部色条正确，但实景从绿色变成明显紫色。这是重要反证：**内部 ISP 通道定义和色条不独立证明真实光学 CFA 相位**，不能把内部色条正常当作实景颜色修复。

随后分别改变 ISP flip、sensor flip、垂直裁剪和偏移，结合光学 RAW 与内部色条对照：

| 配置和插值 | 实板现象 | 同一墙面 ROI 的 G / ((R+B)/2) |
| --- | --- | --- |
| 原 `3820=46`，BGGR | 明显绿色；ISP 内部色条/通道分配为 GRBG | 1.939 |
| 仅 FPGA 改 GRBG | 色条正确，实景明显紫色；否定其作为完整修复 | 不作为成功验收 |
| `3820=42`，BGGR | 内部色条/增益映射变为 BGGR；实景绿调大幅减弱，方向相同 | 1.090 |
| `3820=44`，GRBG | 实景倒置且紫色，不采用 | 0.542 |
| 垂直裁剪末端 `3807=F1`，BGGR | 绿调也大幅减弱，但改变裁剪范围，不采用 | 1.108 |

ROI 使用此前记录的源坐标 `(1200,250)-(1350,600)`，原始分量在保留 Bayer 像素上计算。这是当前暗光场景的辅助数值对照，墙面颜色和光照未标定，不是标准白平衡误差。`3820=42` 选择清除 ISP flip 位，通过一项配置变更修正相位配合；没有加大 R/B 软件增益来掩盖偏绿。

实际读回 `5001=83`、`3406=00` 表明 AWB 使能且为自动模式。单通道增益操作在 `501F=03` 的 DPC RAW 中有选择性响应，因此 AWB 增益确实参与这条路径。`501F=05` 同样不能单独修复相位配合，最终仍使用 `4300=00`、`501F=03`。

[OmniVision OV5640 数据手册（SparkFun 镜像）](https://cdn.sparkfun.com/datasheets/Sensors/LightImaging/OV5640_datasheet.pdf)在 4.1、4.3、5.3、5.12 和 7.4 节定义翻转、内部色条、RAW 输出及白平衡控制。上述映射和修复选择来自实板对照，不是只根据寄存器名称推断。

## 最终实现和验证状态

`ov5640_init.v` 仅在 profile 5 覆盖 `3820=42`，初始化读回也明确核对 42。真实摄像头普通顶层和 DDR3 顶层显式使用 BGGR。Bayer 模块保留此次诊断增加的静态排列参数，默认及最终值均为 0/BGGR，不引入逐帧处理或额外帧缓存。

四种排列各三帧 16×8 的独立参考、边界、随机停顿和 abort 验证通过；GRBG 候选和最终 BGGR 的 FHD 恒定已知颜色场均逐像素验证。profile 5 的 SCCB 初始化、读回、NACK、错误恢复、补光读回及超时仿真通过。

最终构建 `full_20260928_105205` 已下载到板卡 SRAM。166 项构建输入及产物哈希一致，JTAG DONE=1、EOS=1、CRC ERROR=0；bitstream SHA256 为 `890676c106fb66b9ac7a5558ee2f0cc7c853d8b01a0a415f0ee6d7afeb2c554b`。路由后 WNS +0.002 ns、WHS +0.005 ns、TNS/THS 0，时序裕量较窄；DRC、CDC、bus-skew 和 USB 外部时序检查通过。资源为 LUT 18464、FF 20831、BRAM 32、DSP 45。
