# 板内稳健降噪 v2（2026-09-28）

当前主工程已移除 DDR3，历史构建和资源数字保留原记录。当前实现及验证入口见 [无 DDR3 图像链路](无DDR3图像链路.md)。

本文记录降噪专项实现和历史安装。当前固件保留此降噪模块，并在 YUV422 后加入灰度、二值化及 Sobel；最新安装与验收见 [板内图像预处理](板内图像预处理.md)。
首版 RGB 3×3 sigma 滤波的实板 JPEG 载荷下降，但用户在强度 32 下仍看不到明确的噪点改善。旧版工程验收及主观反馈保留在《板内空间降噪.md》和 `denoise_acceptance_20260928`；不能把载荷下降作为画质改善证据。

本版针对两个不足调整：有噪点的中心像素不再决定哪些 RGB 邻居能参加滤波；彩色噪声使用更大的空间邻域。链路为：

`OV5640 RAW8 → BGGR 去马赛克 → YCbCr444 → 3×3 中值混合 → 两级亮度引导色度平滑 → YUV422 → 独立 JPEG → USB`。

没有前一帧输入、DDR3 帧间参考、运动补偿或时间平均。相机 profile 5、`3820=42` 的 Bayer 修正、三档 JPEG 量化、板卡启停、KEY/LED 和短暂补光继续使用原有逻辑。PC 只显示和控制，不做软件降噪。

## 强度含义

- N0：所有像素逐字节保留，仍经过相同流水线，用作对照。
- N1～31：原像素与当前 3×3 邻域中值混合，比例为 `min(N,32)/32`，加 16 后除以 32 四舍五入。对 Y/Cb/Cr 分别求中值。
- N32：完全使用中值，可替换孤立亮点和彩色离群点。弱 8 为四分之一中值，中 16 为一半中值。
- N>32：中值比例不再增大，但色度平滑接受更大的亮度差。255 只用于极端范围验证，不作为默认画质。

中值由九个当前帧样本排序决定，不以中心像素的差值筛掉邻居。中值之后，Y 不再参与平均；Cb/Cr 各执行两次 3×3 高斯平滑，权重为 `1,2,1;2,4,2;1,2,1`，加 8 后除以 16。邻居的中值后亮度与中心亮度差不超过 N 时参与，否则替换为中心。这样不依据带噪色度筛选邻居，并在高亮度反差处抑制跨边界色度平均。在平坦区域两级平滑形成有效 5×5 色度邻域。

这仍是有损空间处理：3×3 中值可能削弱细线和纹理，相同亮度但不同颜色的边界也可能变软。它不估计噪声方差，无法保证完全清除暗部噪声。是否比旧版更好必须由实板 N0/N16/N32 的噪点与细节对照确认。

## 流控与配置

每个窗口只缓存当前帧两行 24 bit YCbCr，边界使用反射；最后一行采用合成读取，输出尺寸不变。中值排序、混合与色度比较、求和分级流水化。像素、有效位、SOF/EOL/EOF 和输出色度奇偶位置一同接受反压；abort/复位清除有效位，新帧覆盖行缓存。

强度在第一窗口接受 SOF 时锁定，并随像素向后传递。后级在该 SOF 上锁定的是同帧的强度，避免 PC 在多行延迟期间改设置，导致不同阶段误用两个值。帧内修改从下一帧生效。

控制命令保持 `Nxx\n`，xx 为两位十六进制，0～255。状态配置字 bit 10 仍表示降噪能力，新增 bit 11 标记稳健降噪 v2；低 9 bit SCCB 索引及高 16 bit 帧计数不变。查看器显示 `稳健降噪 v2 请求强度`。状态读回是请求值，不是逐 JPEG 的强度元数据，逐档测量先停止、设置、等读回，再开始。
