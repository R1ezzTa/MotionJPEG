# 无 DDR3 摄像头链路

最终目标为单路 1080p30 独立 JPEG：OV5640 RAW8 → BGGR 颜色重建 → YCbCr 空间降噪 → YUV422 预处理 → JPEG → MBLK → 同步 USB。顶层为 `davinci_mjpeg_camera_top`，编码与控制域为 100 MHz，USB CLKOUT 域为 60 MHz。

OV5640 profile 5 使用 `3820=42`与 BGGR 光学相位。DVP 输入引脚寄存器与采样 MMCM 分离外部时序，像素经异步 FIFO 进入编码域。首个 HREF 字节决定整帧接收；忙或设置待切换时拒绝新帧。发生短行、溢出或采样时钟丢失时终止当前帧，编码器恢复量化表后可继续接收。

`mjpeg_camera_engine`负责帧生命周期、Q60/Q75/Q85 量化表加载、成功／失败 FPS、状态和封包。摄像头运行请求与画质在 FPGA 内管理。停止排完已接收帧；新画质在帧间更新。

空间降噪采用 YCbCr444 的 3×3 中值混合及两级亮度引导色度平滑，再转换为 YUV422。强度 0 精确保留原像素，8/16/32 对应四分之一／一半／完整中值混合；更高强度放宽平滑门限。降噪可能损失细节，实景画质评价仍需比较相同场景。

预处理支持彩色、灰度、二值化、Sobel。二值化使用亮度阈值，Sobel 使用边缘阈值，二者各 0～255、整帧生效。Sobel 保留过阈值的灰阶边缘强度；弱边缘归零。3×3 边界采用反射，算术流水线支持连续像素。

JPEG 每帧独立，不使用旧参考帧。不存在 DDR3 控制器、块复用或自适应系数阈值。板载 DRAM 的 `ddr3_reset_n`固定为 0，保持复位。

同步 USB 使用 8 KiB TX 和 256 字节 RX 跨时钟 FIFO，统计通过原子快照跨域。FIFO 满时背压是正常协议行为；灰码同步、复位同步、数据与描述符一致性检查均保留。

构建由 `scripts/camera_sources.txt`列出源码，`build_camera.tcl`验证综合／实现的 CDC、总线偏斜、建立／保持时序、DRC、USB 三态释放和 LUT ≤80%。编程前校验构建输入与 bitstream 哈希，避免源码已变却下载旧构建。

最终上板基线和精简验证见[验证说明](验证.md)。协议见[MJPEG 接口](MJPEG接口.md)。
