# 无 DDR3 图像链路与算术流水线优化

当前主工程为 `davinci_mjpeg_camera_top`，默认 OV5640 RAW8 BGGR、1920×1080、30 fps，核心 100 MHz，USB FT245 60 MHz。保留彩色、灰度、二值化、Sobel、空间降噪、三档 JPEG 画质、PC/板载启停、补光和 LED/数码管。

## 移出的硬件

- 主工程不再实例化 MIG、DDR3 事务桥、历史帧缓存，也不再产生 200 MHz DDR 参考时钟。
- 摄像头就绪和中止条件不再依赖 DDR3 校准或故障状态。
- DDR3 复位脚 F4（LVCMOS15）固定为低，使板载存储器保持复位；没有读写或内存时钟。引脚电压和位置沿用此前验证的 MIG 约束。
- 旧控制器、IP、板级顶层和构建脚本已从当前目录归档到 `legacy/ddr3_20260929/`。旧帧间算法的库代码和离线兼容仍可作为历史实验资料；当前 `camera_sources.txt` 不包含帧间比较/参考重建模块，构建也检查网表中不得残留这些实例。
- 共享编码器接口暂保留历史内存端口，当前顶层将输入明确接零、输出留空；综合会移除这些常量路径。

## 算术与并行处理

### Sobel

原先在一级内完成多次差分/加法，下一阶段同时完成绝对值和求和。新实现分为五级：四组邻域差分并行计算、横/纵梯度并行计算、两个绝对值并行计算、幅度求和、阈值与输出选择。两条对角差分同时供 Gx/Gy 使用。

所有级使用同一个反压使能；像素、模式、阈值和 SOF/EOL/EOF 同步延迟。仍可每个允许周期处理一个像素，额外延迟两周期（100 MHz 下 20 ns），输出数值、归一化和阈值含义不变。该优化用于缩短组合路径，不增加摄像头设定帧率，也不代表端到端速度已经提高。

### 中值降噪混合

旧公式为 `original*(32-alpha) + median*alpha + 16`，新公式为 `original*32 + (median-original)*alpha + 16`，结果都取除以 32 的整数部分。使用显式有符号差值和足够的累加位宽，保留相同舍入。

三个 Y/Cb/Cr 通道仍并行处理，每通道只保留一次变量乘法；单独增加一级差值寄存器，避免把节省乘法器换成更长组合路径。用 `use_dsp` 将三个乘加明确映射到 DSP，总数从原先 6 个减为 3 个；否则 Vivado 会把这些小乘法映射到较紧张的 LUT。常量 16 与 `original<<5` 合并为拼接，不增加加法器。延迟增加一周期，吞吐仍为每个允许周期一个像素。新增强度 1/31/32/255 下 0↔255 孤立点测试，覆盖正负差值和舍入边界。

### 同条件独立模块综合对比

Vivado 2020.1，器件 `xc7a35tfgg484-2`，1920×1080，100 MHz；比较脚本和原始报告在 `work/no_ddr3_20260929/compare_arithmetic.tcl` 及相邻 `arithmetic_*` 目录。

| 模块 | LUT（旧→新） | FF（旧→新） | DSP（旧→新） | 最长寄存器数据路径估算（旧→新） |
|---|---:|---:|---:|---:|
| 预处理 / Sobel | 311→384 | 496→559 | 0→0 | 4.345→3.469 ns |
| 三通道中值与混合（含窗口） | 1269→1321 | 942→960 | 6→3 | 8.734→5.736 ns |

增加少量寄存器、配置延迟和控制逻辑，换取较短的算术组合路径，同时节省三个 DSP。这是未布线综合估算，不能当成整机最高频率或帧率。两处原本都能每周期处理一个像素，因此此次分级并行不会直接把 30 fps 提高；它主要降低单级运算压力。最终整机资源与时序另见验收结果。

## 2026-09-29 最终布线结果

最终构建：`reports/camera/full_20260929_170515/`。对比基线为移除 DDR3 前已验收的 `reports/ddr3/full_20260929_153849/`，两者均保留空间降噪和四种预处理模式。

| 资源 | 原版本 | 当前版本 | 当前剩余 |
|---|---:|---:|---:|
| LUT | 19410 / 20800（93.32%） | 15584 / 20800（74.92%） | 5216（25.08%） |
| FF | 22996 / 41600（55.28%） | 19533 / 41600（46.95%） | 22067（53.05%） |
| BRAM36 等效 | 36 / 50（72%） | 36 / 50（72%） | 14（28%） |
| DSP | 49 / 90（54.44%） | 46 / 90（51.11%） | 44（48.89%） |

净释放 3826 个 LUT、3463 个 FF、3 个 DSP。BRAM 用于编码、图像行缓存和 USB 缓冲，当前功能仍需要这些片内存储。LUT 节省主要来自退出 DDR3 控制链路；算术分级本身会增加少量寄存器和控制逻辑。

全局 WNS **+0.057 ns**、WHS **+0.023 ns**，TNS/THS 均为 0；100 MHz 核 WNS **+0.057 ns**。最紧路径为 JPEG 通道的 `inflight` 状态经反压链到采集 FIFO 读使能，已不在所修改的 Sobel/中值算术路径。整机核心时序余量比旧版本 +0.601 ns 小，不能把局部综合路径改善称为整机提速，也不据此提高核心时钟。

无黑盒、无 DDR3/帧间引用实例、无 DDR 时钟；DDR 相关顶层端口仅有固定低电平的复位脚。CDC 无 Critical，DRC 无 Error，Gray bus skew 与八路 USB 三态释放检查通过。报告仍包含 DSP 流水级、RAM 异步复位控制及已有摄像头时钟布局等 Warning；本次没有隐藏或降低它们的级别，也没有新增摄像头/USB 数据时序豁免。
