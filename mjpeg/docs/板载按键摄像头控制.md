# 板载按键摄像头控制

真实摄像头顶层使用达芬奇四个低有效板载按键。上电／RESET 后默认停止输出，选中高画质 Q85，补光关闭。按键经过两级同步和 20 ms 消抖；长按只执行一次，松开后再次按下才能再次触发。

| 按键 | 功能 | 行为 |
| --- | --- | --- |
| KEY0 | 开启／停止 MJPEG | 开启后自动等待传感器初始化完成；停止时完整输出正在编码的帧，再发送 END |
| KEY1 | 循环切换画质 | Q85 → Q60 → Q75 → Q85；停止时可提前选档 |
| KEY2 | 补光约 2 秒 | 由 FPGA 计时并通过 SCCB 写入及读回确认；无需 PC 计时。再次按下会重新计时 |
| KEY3 | 停止并取消补光 | 同时按多个键时停止优先 |
| RESET | 恢复默认状态 | 重新初始化，默认停止、Q85、补光关闭 |

| LED | 指示 |
| --- | --- |
| LED0 | MJPEG 工作时亮，停止后灭；请求开启但初始化尚未就绪时慢闪 |
| LED1 / LED2 | 低档 Q60：两灯灭；中档 Q75：仅 LED1 亮；高档 Q85：仅 LED2 亮 |
| LED3 | 补光寄存器读回确认开启时亮；初始化、补光控制或编码出现错误时快闪 |

工作时画质灯显示已生效的档位，停止时显示下次开启将使用的档位。切换过程中停止新帧准入，排空已准入图像，再写完全部 128 个量化值及倒数后恢复；保留分辨率、帧号和编码时钟，不复位 JPEG 通道。一帧始终使用同一套表。切换瞬间允许暂停准入，连续稳定输出时仍以 1080p30 为目标；场景复杂度会影响码率。

“停止”关闭图像准入、编码输出和补光，保留传感器初始化，便于快速重启。USB_SLAVE 和 PC 接收程序仍须打开，提供 60 MHz FT245 时钟并及时读取数据。本工程尚未用 DDR 缓冲离线视频。USB 重开可能复位传感器和传输链路；板载控制器使用独立复位，保留按键选择的启停及画质状态，RESET 才恢复默认。

默认仅接收，等待 KEY0 开启；KEY0／KEY3 停止后窗口继续等待，再次开启无需重开窗口。底部显示实际 Q 值、待生效档位和补光状态。空格冻结显示、S 保存原始 JPEG，Esc 发送停止和关灯命令并关闭。`--auto-start` 保留 PC 自动发 C 的旧方式；历史固件须加此选项。窗口内 L 补光请求与板载 KEY2 进入同一个 FPGA 控制器，计时仍在 FPGA。

## 引脚和遥测

KEY0/1/2/3 分别为 T1/U1/W2/T3，LVCMOS33、上拉；LED0/1/2/3 为 R2/R3/V2/Y2，高有效。异步按键仅到第一级同步寄存器的路径被排除，后续逻辑正常计时。

MBLK type 7 的 flags 扩展：bit16 表示板载控制存在，bit17 为请求运行，bits19:18 为生效画质索引，bits21:20 为请求画质索引，bit22 表示等待切换；索引 0/1/2 对应 Q60/Q75/Q85。旧字段和 32 字节长度保持不变。USB `C`/`S`/`L`/`l` 保留兼容，`Q` 循环画质，`1`/`2`/`3` 选 Q60/Q75/Q85，用于自动上板验收；这些命令更新同一个板端控制状态。
